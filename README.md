# TerraGrid 3D

3D urban heat digital twin for councils. Globe → city fly-in → extruded buildings glowing by surface heat,
satellite layers (Copernicus CAMS via Open-Meteo, NASA GIBS), precinct stats, and a cool-roof / canopy
scenario simulator with live KPIs.

Built for Climate Hack-tion 2026 (EU + MLAI), Track 3: Resilient Cities & Buildings.

Status: planning done, build in progress. See `TODO.md`. Hackathon research in `docs/hackathon/`.

```bash
npm install
npm run dev
```
